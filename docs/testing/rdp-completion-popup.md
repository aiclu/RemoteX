# RDP 额外指令补全弹层修复

2026-09-24，版本 1.0.16，仅本地修改。

## 变更

- RDP 文件设置、控件设置和 RemoteApp 文件设置共用弹层创建与关闭逻辑。
- Fluent 弹层独立接入局部外观服务，列表及候选项跟随当前页面明暗配色；经典使用原主题资源。
- 宽度最多 420 DIP，高度最多 240 DIP，并按所属窗口缩小；滚动保留。候选说明原本仅重复名称，现不再显示重复提示框。
- 仅可见且具有键盘焦点的编辑器允许创建补全窗口；空字段从获得焦点触发改为明确点击触发，避免关闭后焦点恢复再次弹出。
- Escape、点击所属窗口的其他位置、失焦、所属窗口失活/移动/缩放、页面滚动和卸载均关闭弹层。关闭时移除事件和主题监听。

## 验证

- Debug 构建通过，47 项专项测试通过；新增测试覆盖无焦点/不可见/空候选不允许打开，以及常规和窄窗口尺寸约束。
- 尚未实机验证：明暗弹层、真实 Escape 和外部点击、Enter/Tab/鼠标插入、连续打开关闭、协议切换、窗口跨 DPI 显示器移动。自动测试不等同于这些交互已通过。
