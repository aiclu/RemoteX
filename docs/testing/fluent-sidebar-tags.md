# Fluent 侧栏标签固定

## 行为

- 侧栏使用独立 ListCollectionView，依次按 IsPinned 降序、CustomOrder 升序、Name 升序排列；不排序共享 HeaderTags 或其默认视图。
- 固定标签显示图钉，普通标签保留相同图标空间，文字对齐；长名称省略并保留完整 Tooltip。
- 右键菜单复用 Pin / Unpin 文案与既有 CmdTagPin；保存仍由原标签模型处理。
- 监听当前页面 HeaderTags 替换，切换视图、关闭 Fluent 或卸载时释放旧排序视图及订阅。LiveSorting 处理固定、名称和顺序通知。
- 单个滚动区，固定标签随列表滚动；保留侧栏虚拟化、Alt 单击排除筛选及底部固定入口。

## 验证

- Debug 构建成功，完整 C# 测试 93 项通过（含新增 5 项标签测试）。
- 验证独立排序、原集合和默认视图顺序不变、实时通知、增删清空、20 次排序视图创建释放、原 JSON 固定状态往返及实际 XAML 图钉／菜单状态绑定。
- 隔离渲染使用 403 个模拟标签，输出明暗主题、176/140 DIP 宽度、普通／大字体及 100%/150%/200% 图片；断言第 300 项未创建容器。已目视检查明暗 100% 样例中的图钉、对齐和省略。
- 未执行真实用户配置写入、应用重启、连接或删除标签。真实鼠标菜单、视图切换、重启持久化和实机 DPI 验收仍需用户确认；自动测试的 JSON 往返不等同于整机重启验证。
- 独立测试目录：`Ui/bin/TagPinTest`；包含 `RemoteX.exe`、`ssh_rust.dll`。渲染样例位于 `Ui/bin/FluentDialogsTest/screenshots/SidebarTags-*.png`。
