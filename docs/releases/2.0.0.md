# RemoteX 2.0.0 — Fluent 与 .NET 9

## 主要变化

- 可选 Fluent 外观覆盖主界面、设置、连接编辑器、启动器、常用弹窗、会话窗口边框和连接视图；支持浅色、深色、跟随系统与系统高对比度配色。
- 紧凑侧栏、全部连接入口、标签筛选、搜索图标与快捷键提示；协议栏采用清晰正文色和选中下划线。
- 主窗口菜单去重，退出迁至“更多”；视图、排序、外观菜单统一配色并显示当前选项／排序方向。
- 保留经典外观与其原有配置；Fluent 首次启用使用独立列表视图偏好。不修改远程协议内容的渲染方式。
- 支持的主程序、依赖库与测试统一到 .NET 9；移除 .NET 6／.NET Framework 构建配置。历史 DragablzModernUIDemo 不在支持范围。

## 修复

- 语言资源重复键及隔离宿主中的资源加载。
- 隐藏搜索框同步导致输入光标回到首位。
- RDP／RemoteApp 编辑器补全弹层的尺寸、主题与关闭条件。
- 空密码加密触发 SSH 密码 setter、意外清空私钥；增加两种认证模式的往返测试。无法恢复此前已丢失的数据。
- 测试初始化与临时数据隔离；更新过时的数据库和配置测试。

## 升级与兼容

- 下载 `RemoteX-2.0.0-net9-x64-self-contained.zip` 可免装 .NET；框架依赖版 `RemoteX-2.0.0-net9-x64.zip` 需要 .NET 9 Desktop Runtime x64。
- 请完整解压，保留 `ssh_rust.dll` 和 `updater.exe` 等依赖。升级前备份配置和连接数据库，手动替换文件前退出程序。
- 既有配置默认保持经典模式；通过“设置 → 主题 → Fluent 预览”启用新外观。
- 本次不变更用户数据格式；共享库不再支持旧框架目标。

## 验证与限制

- 发布前完整 C# 测试 85 项通过，Dragablz 测试 21 项通过，均无跳过；Debug 构建通过。正式 ZIP 由 GitHub Actions 构建。
- 已包含语言加载、搜索光标、菜单状态、配置保留、敏感字段加密等自动化回归。隔离 WPF 渲染不等同于实机 DPI／键盘鼠标验收。
- 不宣称所有系统主题、高对比度、多显示器及 100%／150%／200% DPI 场景完成实机验证；未自动执行真实远程连接或数据库服务写入。
- 已有部分环境自动更新未完成的问题不在本次修复范围；失败时请使用完整 ZIP 手动升级。

## English summary

RemoteX 2.0 introduces optional Fluent styling with light, dark and system themes while preserving classic preferences. The supported application and test projects now target .NET 9 only. This release improves navigation, search and protocol selection, fixes language loading and caret/completion issues, and preserves SSH private keys when encrypting sensitive fields. Back up your configuration and databases before upgrading and extract the complete package. Automatic-update failures reported in some environments are not claimed fixed; use the release ZIP if needed.
