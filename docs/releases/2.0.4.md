# RemoteX 2.0.4

本次更新完善 Fluent 启动器和会话标签栏，并补充首页备选连接入口。经典外观、现有连接流程和数据格式保持不变。

## 修复与改进

- 首页列表在配置了备选连接时显示下拉入口，复用现有备选凭据连接命令；普通“连接”行为不变，列表回收或切换连接时清理旧菜单。
- 会话标签栏统一底色，使用紧凑圆角标签和短选中指示线，协调标志、协议图标、关闭、重连及新增按钮。保留原有 30 DIP 栏高、远程内容尺寸和拖动部件。
- 启动器保留 400 DIP 默认宽度与最多八条可见结果，统一搜索、结果、操作列表、Tab 快速连接和备注面板的局部 Fluent 样式。
- 搜索区域增加图标与快速连接提示，筛选标签独占一行；名称、地址及协议信息分层显示，长文本和命中高亮可省略。隐藏账号信息时，提示文字也不会重新显示账号。
- 选中项采用淡色背景及左侧强调线，连接标记色单独呈现；字体增大时行高随文本调整，窗口高度同时计入筛选标签和当前显示器工作区限制。
- 保留搜索排序、键盘命令、列表虚拟化和备注编辑逻辑；补充 14 种语言的启动器提示资源。

## 验证与已知限制

- 本地 Debug 构建通过，完整 C# 测试 **139 项通过、0 失败、0 跳过**。
- 使用真实模板与模拟数据检查会话标签栏、启动器结果、操作、快速连接及备注，覆盖明暗主题、长文本、隐藏账号、10–20 DIP 字体、窄工作区和 1200 条结果的虚拟化。
- 全部 14 种语言资源可加载；独立 Debug 测试目录中的 `ssh_rust.dll` 通过加载及日志回调导出检查。
- 100%／150%／200% 图片是隔离渲染输出比例，不代替实机 DPI 验证。真实拖放、跨显示器 DPI、中文输入法、全局热键、失焦隐藏及远程会话切换仍需实机验收；本地自动测试不执行真实连接、凭据修改或备注保存。
- 已有部分环境自动更新未完成的问题不在本次修复范围。升级前备份配置和连接数据库；更新失败时退出应用，完整解压发布 ZIP 手动升级并保留原数据。

## English summary

Adds an alternate-connection menu to the Fluent home list, coordinates compact rounded session tabs, and refines the launcher's search results, actions, quick connection and notes. Classic appearance, connection behavior and data formats remain intact. All 139 C# tests pass locally; synthetic rendering checks do not replace real-device DPI, IME, hotkey and drag-and-drop validation. Existing automatic-update failures are not claimed fixed.
