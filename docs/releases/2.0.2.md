# RemoteX 2.0.2

## 修复与改进

- 修复 Fluent 侧栏切换标签后旧标签仍残留选中底色的问题：高亮跟随当前标签筛选，不再受列表内部选中项影响。
- Fluent 列表／卡片视图中的各数据源改为独立圆角卡片。折叠后仅显示标题栏，方向箭头、名称、选择框和右侧操作区对齐，长名称省略并提供提示，错误说明独立换行。
- 修复数据源先展开再折叠时的红色校验边框：移除布尔折叠绑定中不适用的空值标记，保持折叠状态正确写回和保存；未关闭校验或隐藏错误装饰层。
- 修复“管理标签”顶部露出连接列表的多余区域。管理标签与连接列表互斥显示，Fluent 列表模式移除旧标题栏留白，返回后保留数据源折叠状态。
- 保留经典外观、树形视图、标签筛选及原有命令和存储格式，不增加配置项；列表和卡片虚拟化保持启用。

## 验证与已知限制

- 本地 Debug 构建通过，完整 C# 测试 104 项通过、0 失败、0 跳过，覆盖标签高亮、折叠双向同步和持久化、分组操作、管理标签切换及面板恢复。
- 隔离渲染覆盖明暗主题、窄窗口、长名称、空组和错误状态；1200 条模拟连接通过列表／卡片虚拟化检查。
- 管理标签使用真实编译的页面和模拟数据反复切换，确认没有旧顶部空隙并保留折叠状态。100%／150%／200% 输出比例不等同于实机 DPI 验证。
- `ssh_rust.dll` 已通过本地加载及日志回调导出检查。未执行真实远程连接、数据库修改或软件升级。
- 实机拖放、键盘焦点、显示器 DPI、系统主题动态切换和真实数据源重启恢复仍需进一步验收。
- 已有部分环境自动更新未完成的问题不在此次修复范围。升级前备份配置及连接数据库；更新失败时退出应用，完整解压发布 ZIP 手动升级，保留原数据。

## English summary

Fixes stale Fluent sidebar tag highlights, introduces separate rounded data-source cards, and corrects the collapse binding that caused red validation borders and failed state updates. Tag management no longer exposes the connection list through an obsolete top gap. Existing commands, storage, classic appearance, tree view and list/card virtualization remain intact. Local Debug builds and all 104 C# tests pass; isolated rendering is not a substitute for real-device DPI and interaction testing. Existing automatic-update failures are not claimed fixed.
