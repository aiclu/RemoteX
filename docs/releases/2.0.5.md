# RemoteX 2.0.5

本次更新统一连接编辑器中的凭据区域与添加／编辑凭据弹框的 Fluent 外观，修正蓝色粗边框、字段错位和校验提示拥挤。经典模式、密码遮罩、凭据保存逻辑与数据格式保持不变。

## 修复与改进

- 凭据区域改为自适应细边圆角面板；手动输入与凭据库选择采用文字和短下划线，移除 Fluent 模式下的粗蓝框和固定宽度，减少窄窗口裁切。
- 统一用户名、密码、私钥及凭据库选择的间距和布局，支持大字体与长模式名称，保留密码显示授权、文件选择和现有命令。
- 添加／编辑凭据弹框统一为标签在上、输入框在下；错误提示独占输入框下方一行，不再覆盖输入内容，原有必填、重名及端口校验继续生效。
- 保存与取消固定在底部，正文在可用高度不足时滚动；私钥选择按钮拥有独立区域，不再覆盖路径输入框。
- 凭据库弹框移除不适用的“留空继承默认值”提示，备选连接弹框保留该提示。局部样式适配浅色、深色和高对比度，经典外观不变。

## 验证与已知限制

- 已检查明暗主题、300 DIP 窄布局、大字体与长文案；独立测试目录中的 `ssh_rust.dll` 可加载，全部 14 种语言资源可加载。

Unifies the credential panel and add/edit credential dialogs with local Fluent styling. Adaptive panels, compact mode selectors, aligned inputs, inline validation messages and a fixed action area improve narrow-window and large-font layouts. Classic appearance, password masking, validation, save behavior and data formats remain intact. All 153 C# tests pass locally; isolated rendering does not replace real-device DPI, focus or IME validation. Existing automatic-update failures are not claimed fixed.
