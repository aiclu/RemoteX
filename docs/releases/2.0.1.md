# RemoteX 2.0.1

## 修复与改进

- 修复 Fluent 树形视图切换及滚动时的布局卡死：修正标题行尺寸，并仅在 Fluent 树形关闭层级虚拟化。用户已确认测试版恢复正常；列表虚拟化保持不变。
- 完善侧栏标签固定：固定标签优先排列并显示图钉，右键菜单切换“固定／取消固定”，状态即时刷新；全部标签共享滚动区。
- 保留经典标签顺序、现有存储格式、标签筛选和 Alt 单击排除行为。释放旧侧栏排序视图及订阅，避免切换视图后继续监听。

## 验证与已知限制

- 完整 C# 回归测试覆盖侧栏排序、动态图钉和菜单、订阅释放、状态序列化及树形布局。
- 树形真实窗口探针通过 1200 条模拟连接的滚动、展开折叠、大字体和视图切换检查；侧栏隔离渲染覆盖明暗主题与 403 个模拟标签。
- Fluent 树形展开大量节点时会创建更多控件，增加内存和首次布局成本；极大数据集建议使用列表视图。
- 侧栏实机重启持久化、全部 DPI 和键盘鼠标场景尚未完整验收，不将隔离渲染等同于实机测试。
- 已有部分环境自动更新未完成的问题不在此次修复范围。升级前备份配置及连接数据库；更新失败时退出应用，完整解压发布 ZIP 手动升级，保留原数据。

## English summary

Fixes Fluent tree-view layout freezes with a scoped non-virtualized fallback and corrected header sizing. Pinned sidebar tags now appear first with a pin indicator and a state-aware Pin/Unpin menu. Classic ordering and storage remain unchanged. Large expanded Fluent trees use more memory; the list view remains virtualized. Existing automatic-update failures are not claimed fixed.
