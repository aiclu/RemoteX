# RemoteX 2.0.3

## 修复与改进

- 优化 Fluent 首页的对齐和密度：搜索／操作工具栏与数据源卡片统一边缘，侧栏首项与搜索顶部对齐。
- 工具栏在宽窗口内单行显示搜索、视图、排序、更多与添加，空间不足时按实际按钮宽度自动换行，保留同一个搜索框、输入内容和光标位置。
- 数据源标题与连接行共用列尺寸，使复选框、名称及右侧操作对齐；极窄窗口下数据源状态和添加操作移至第二行。保留独立圆角卡片，去除 Fluent 列表旧的底部留白。
- “添加”使用强调色，视图／排序／更多使用轻量下拉按钮，“连接”保持常驻且弱化边框。长名称和极窄窗口下的长按钮文案省略并提供完整提示。
- 侧栏当前标签使用淡色背景及强调色指示条；“全部连接”不会与当前标签或管理标签页同时显示激活状态。浅色、深色与高对比度保持局部主题资源。
- 修复“设置 → 启动器”在关键词匹配器区域无法滚动的问题：移除没有选择用途的内层滚动列表，由页面统一滚动，保留快捷键、匹配选项绑定和保存逻辑。
- 保留经典外观、卡片／树形视图内部、现有命令与数据格式，不增加配置项；连接列表虚拟化保持启用。

## 验证与已知限制

- 本地 Debug 构建通过，完整 C# 测试 **115 项通过、0 失败、0 跳过**。
- 使用真实侧栏、工具栏、分组模板和连接行组成完整模拟首页，检查 300–1120 DIP 宽度、明暗主题、大字体、长文案、折叠／展开、只读／错误／空数据源和反复缩放；正常布局对齐误差不超过 1 DIP。
- 1200 条模拟连接滚动时实际生成 22–56 行容器；原卡片分组和管理标签返回回归通过。启动器设置在复选框、说明和空白处均可滚动至底部并返回。
- 全部 14 种语言资源加载成功，独立 Debug 测试目录中的 `ssh_rust.dll` 通过加载与日志回调导出检查；未执行真实远程连接、数据库修改或自动升级。
- 100%／150%／200% 截图是隔离渲染输出比例，不替代实机 DPI 验证。跨显示器、鼠标拖放、真实窗口焦点／中文输入法、系统主题动态切换及系统高对比度仍需实机验收。
- 已有部分环境自动更新未完成的问题不在本次修复范围。升级前备份配置和连接数据库；更新失败时退出应用，完整解压发布 ZIP 手动升级并保留原数据。

Fixes scrolling over keyword matchers in Launcher settings. Classic appearance, existing commands, data formats and list virtualization remain intact. All 115 C# tests pass locally; rendering and synthetic interaction checks do not replace real-device DPI, keyboard/IME and drag-and-drop validation. Existing automatic-update failures are not claimed fixed.
