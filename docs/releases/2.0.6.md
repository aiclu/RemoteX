# RemoteX 2.0.6

本次补丁为 SSH 终端初始化增加异常保护与依赖恢复提示，并清理错误反馈弹窗中的旧联系方式。连接配置、凭据格式和更新实现保持不变。

## 修复与改进

- 终端依赖缺失或无法加载时，在当前会话标签中提示彻底退出 RemoteX（包括系统托盘）后重新打开；依赖不兼容或损坏时提示重新解压对应架构的完整官方安装包。
- 捕获终端控件创建、连接绑定等初始化异常，释放本次连接资源，保留关闭与重试入口，不再让这类异常直接进入全局错误弹窗。
- 关闭标签或重新连接后忽略旧连接迟到的结果与事件，避免覆盖当前会话状态。普通认证错误保留原有错误信息，不误报为依赖缺失。
- 新增初始化诊断记录异常类型、HRESULT 和调用栈，不记录异常消息中的潜在凭据、连接参数或启动命令。
- 错误反馈弹窗移除 QQ 群和邮件入口；GitHub 显示地址统一为 `github.com/aiclu/RemoteX`，点击打开本仓库的 Issues 页面。提示文案同步至全部 14 种语言资源。

## 验证与已知限制

- 本地 Debug 构建通过，完整 C# 测试 **167 项通过、0 失败、0 跳过**，其中 14 项为本次新增测试。
- 覆盖嵌套 DLL 加载异常、依赖不兼容、清理异常、重试与关闭、过期连接结果、认证错误区分，以及诊断信息中的敏感内容排除。
- 使用真实终端控件验证初始化与关闭，不连接服务器；检查反馈弹窗的明暗主题渲染、GitHub 地址及关闭行为。独立测试目录中的 `ssh_rust.dll` 与 x64 `Microsoft.Terminal.Control.dll` 可加载。
- 本次不自动删除解包缓存、不强制重启应用。若提示重启，请先结束其他活动会话，再从系统托盘彻底退出 RemoteX；仍失败时重新解压完整官方安装包。
- 自动测试未执行真实 SSH 连接或升级。已有部分环境自动更新未完成的问题不在本次修复范围。

## English summary

Adds guarded terminal initialization, clear recovery guidance for missing or incompatible dependencies, connection cleanup, and stale-callback protection. Initialization failures remain in the session tab with retry and dismiss actions instead of opening the global error dialog. Authentication errors retain their original messages. The feedback dialog removes the legacy QQ/email contacts and points to aiclu/RemoteX on GitHub. All 167 C# tests pass locally, including 14 new tests. No real server connections or upgrades were performed; existing automatic-update failures are not claimed fixed.
